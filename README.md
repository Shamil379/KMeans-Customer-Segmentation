# KMeans-Customer-Segmentation

📂 Dataset

Source: Mall Customer Segmentation Dataset (Kaggle)

Features used:

Annual Income (k$)

Spending Score (1-100)

CustomerID was removed as it does not contribute to clustering.

⚙️ Methodology

Loaded and inspected the dataset

Selected relevant features and applied StandardScaler

Used the Elbow Method to find optimal number of clusters

Trained K-Means with K = 5

Visualized clusters using scatter plots

Added cluster labels to the dataset and saved results

📊 Results

Optimal clusters identified: 5

Customers segmented into groups such as:

High Value Customers

Careless Spenders

Savers

Average Customers

Low Value Customers

🧠 Conclusion

Customer segmentation helps businesses design targeted marketing strategies, improve customer satisfaction, and maximize revenue by focusing on high-value customer groups.
